# Contributing

Issues and pull requests are welcome.

- Do not commit `.env`, `config.json`, `data/`, or any database file.
- Do not commit customer, vendor, or bank data. Demo data belongs in `scripts/seed-demo.js` and must use invented names.
- Keep company names, addresses, and tax rates in Settings or environment variables.
- Node.js 20 or newer.
- Run `npm start`, then open the home page and one module page before sending a change.
